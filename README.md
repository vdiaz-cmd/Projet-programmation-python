# Projet Programmation Python

## Lancer l'application
Pour lancer l'application, suivez les étapes ci-dessous :

1. `git clone https://github.com/vdiaz-cmd/Projet-programmation-python.git` : Clonez le dépôt Git de l'application sur votre machine locale.
2. `cd Projet-programmation-python` : Accédez au répertoire du projet.
3. `cd "projet "` : Accédez au dossier contenant le code source.
4. `python projet.py` : Lancez l'application avec Python.
